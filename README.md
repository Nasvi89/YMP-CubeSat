# YMP-CubeSat

Учебно-методическое пособие: сборно-разборный макет спутника типа CubeSat.

Механическая сборка, подключение электроники, программирование датчиков, снятие телеметрии и итоговое испытание макета.

## Структура репозитория

```
Методическое пособие.html   # главная страница (точка входа)
index.html                  # редирект на главную (для GitHub Pages)
assembly/                   # вкладка «Сборка» — чертёж и инструкция
code/                       # вкладка «Код» — программы и редактор
practice/                   # вкладка «Практика» — лабораторные
diag/                       # вкладка «Диагностика» — неисправности и отчёт
style.css                   # общие стили
app.js                      # общий скрипт (навигация, темы, редактор)
Vector.png / Vector2.png    # логотипы (светлая/тёмная тема)
files/                      # примеры файлов для панели редактора
server.js                   # локальный Node-сервер (для запуска на ПК)
```

## Публикация на GitHub Pages

Сайт публикуется из корня репозитория с помощью GitHub Actions
(`.github/workflows/pages.yml`). После публикации сайт доступен по адресу:

```
https://Nasvi89.github.io/YMP-CubeSat/
```

## Локальный запуск

Просто откройте `Методическое пособие.html` в браузере — сайт статический и
работает без сервера.

Для запуска через Node:

```
node server.js
```

Сайт будет доступен на http://localhost:8080.
